Windows endpoint agent

Put a witness on every Windows machine.

Aegis watches process, network, credential and script activity and reports it to the Aegis console running on your own network. Setup finds the console by itself. You approve the machine, and it's covered in about half a minute.

01 · How it works

Three steps, one of them yours.

Nothing to configure. The laptop needs to be on the same network as the console.
  1. 1

    It finds your console

    Setup broadcasts on the local network. If nothing answers, it checks the nearby addresses for an Aegis console.

    No address or enrollment code to type.

  2. 2

    You approve it

    The machine shows up on the console under Endpoints with its name, user and IP. Click Approve.

    Or switch on auto-approve for a lab you trust.

  3. 3

    It installs and reports

    The console sends the installer. Each step appears live on the console until the first events arrive.

    Usually under 30 seconds on a local network.

04 · Questions

Before you run it.

Requirements: Windows 10 or 11, 64-bit (x64 or ARM64), an administrator account, and the same network as the console.

Windows says it “protected your PC”.

The launcher isn't code-signed yet. Click More info, then Run anyway. You can read the whole script first: it's setup.ps1, about 175 lines.

Where does my data go?

Only to the console you approve on your own network. This site never receives events, and setup talks to nothing else.

Setup can't find the console.

Check the console is running and that both machines are on the same network or VPN. Setup then asks for the address, for example 192.168.1.20:8000.

Why does it ask for administrator rights?

Reading the Security log, installing Sysmon and setting audit policy all need them. Windows asks once, when setup starts.

It's a work laptop with another EDR.

That's fine. If the other product blocks Sysmon, that step is skipped and Aegis carries on with the Security, PowerShell and System logs.

Can someone enroll a machine I don't know about?

Not by default. Every machine waits for an analyst to approve it on the console, unless you turn auto-approve on.
